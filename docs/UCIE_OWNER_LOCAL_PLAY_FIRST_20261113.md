# UCIE 개인용 로컬 완성도 우선: 소유자 직접 체험 4대 기능 (2026-11-13)

프로젝트: UCIE ONLY
결정: 사용자가 먼저 로컬에서 실제로 쓰면서 기능을 점검한다. 정기결제, 지정 고객 배포, 외부 호스팅, 고객용 제품/회원 서명과 C2-C5 상용 인수는 나중으로 보류한다.

## 기존 제품 실행: ONE COMMAND

소유자 Windows PowerShell에서:

    & 'D:\UCIE\scripts\start_ucie_local_v1.ps1'

기존 소유자 로컬 런처가 사용 가능한 127.0.0.1 포트를 선택하고 브라우저를 연다. 브라우저가 자동으로 열리지 않으면 출력된 local_app_url을 복사한다. 과거 다른 서버가 점유한 8767 주소를 임의로 사용하지 않는다. Ctrl+C로 해당 앱만 종료한다. 관리자 권한, 별도 판매 라이선스, 고객명, 결제사업자, 실제 개인키가 필요하지 않다.

## 실제 이번 개선

기존 Local V04 홈의 기존 네 가지 기능 카드 아래에 내 PC에서 바로 사용해보기 섹션을 추가한다. 기존 승인된 첫 파티 기술 사례 Python, PowerShell, Git, MCP 각각에 대해 다음 실제 Local V1 화면으로 이동하는 링크를 제공한다.

1. /local/error?case=... : 고정 공식 자료에 근거한 사람이 확인할 오류 점검
2. /local/engine?purpose=B2_CONNECTED_TRIAGE&case=...&scenario=issue : UCIE 코드가 실행하는 고정 합성 오류 상황 판정 및 control 대조 시험
3. /local/library?q=... : 기존 UCIE 공개 기술 원장, 공식 자료, 검토 중 SkillBook 검색
4. /local/evolution?q=... : 동일 공개 기술 분야의 수집 개정 및 개선 근거 검토

기존 엔진/공개 근거의 결과를 재사용한다. 로컬 페이지를 새 대시보드로 복제하거나 외부 고객 코드/로그를 받아들이지 않는다. 고정 합성 판정을 사용자 실제 환경 진단이나 승인된 수정으로 속여 표시하지 않는다.

## 개인용 제품과 고객 배포는 다른 판단

현행 Local V1은 2026-11-08 소유자 로컬 인수 이력이 있고, 소유자 4가지 실경로 READ-ONLY 시험을 다시 확인했다. 그러나 개인용 네 축 연결만으로 임의 고객 프로젝트의 모든 오류를 독립 검사하거나 모든 SkillBook이 승인된 완성된 재사용 기술임을 증명하지는 못한다. 실사용하면서 구체적 기능 결손을 계속 고쳐 나갈 수 있다.

이번 변경은 운영 DB, 기존 공개 수집기, Windows 예약 작업, 고객 서명키, C40, Cloudflare, 기존 서비스 재시작, 파일 배포나 결제설정을 수정하지 않는다. 상용 배포 NO_GO는 유지한다. 소유자에게 유료 서비스, 법무 승인, C4 실물 고객 PC 준비를 요구하지 않는다.

## 인수 조건

코드상 고정 4개의 체험 흐름, 기존 4대 화면 연결, 8개 연결형 엔진 HTTP GET, localhost 외부 Host 차단, POST 405, CSP, 합성 경계, 기존 로컬 홈 회귀 시험과 소유자 기존 공개 원장 읽기 경로가 모두 안전해야 한다. 실제 브라우저 사용자 경험은 소유자 Windows에서 실행해 최종 확인한다. 새 소스는 기존 미커밋 파일을 덮지 않고 SHA lease/백업 후 적용한다.
