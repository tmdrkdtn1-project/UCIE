# UCIE 내부 엔진 우선 · 외부 AI 호출 제로 경로 (2026-11-02)

## 사업·기술 의사결정
UCIE의 대량 작업을 대화형 ChatGPT 또는 유료 모델 API의 반복 호출에 의존시키지 않는다. **규칙 기반의 결정론적 작업은 UCIE 자체 코드와 비차단 내부 worker가 수행**한다. 출처가 승인된 공개 자료만 처리하고, 고객/타 프로젝트의 비공개 자료를 UCIE의 공용 지식 자산으로 수집하지 않는다.

*Zero external AI cost*는 외부 유료 **생성형 모델 호출**을 하지 않는 특정 코드 경로의 관측값이지, **전체 서비스 원가 0** 또는 **실제 지능형 재가공 완성**을 뜻하지 않는다. CPU·메모리·디스크·서버·운영·검증·모델을 로컬에서 실행할 경우 GPU/전력/유지보수 비용은 계속 발생한다.

## 실제 기존 UCIE 코드 재사용
- `src/ucie_miner/runtime_pipeline.py`: 기존 P10 1분 비차단 dispatcher; 최대 3개 별도 프로세스 worker, 임대·heartbeat·180초 예산·타임아웃/재시도. 실제 Windows 활성화는 별도 호스트 영수증 필요. 새 스케줄러 설치 금지.
- `src/ucie_miner/pending_queue.py`: 고정 작업 종류만 허용, 차단된 작업은 PENDING·후속 작업 독립 진행, SQLite 안전 임대.
- `src/ucie_miner/library_entry.py`: 공개 출처·근거·버전 메타데이터 경계 강제.
- `src/ucie_miner/skillbook_blueprint.py`: 승인 공개 후보 메타데이터를 아직 미검증/반출 불가한 스킬서적 구조로 분류.

## 이번 구현: 내부 배치 처리의 작은 실증
`src/ucie_miner/internal_skillbook_batch.py`는 외부 생성형 AI나 네트워크, 파일·운영 DB에 의존하지 않고 기존 `compose_blueprint`를 메모리 배치로 호출한다. 입력당 최대 8개의 업무, 전체 후보 80건, 개별 업무 64KiB. 요청 내용 전체를 외부에 보내지 않고, 같은 호출 내 동일 업무 결과 재사용(해시 기반 dedup), 메타데이터별 고정 상태를 반환한다. 승인/검증·배포 상태는 항상 false. 요청 카운터, 로컬 캐시 히트 및 AI/API 호출 건수 0을 결과에 명시한다. 이것은 **메타데이터 처리 로직**의 AI 호출 비용 0에 해당하며, 실제 운영 P10 worker 종류를 추가하지 않았다.

`tests/test_ucie_internal_skillbook_batch.py`는 미승인 출처·승인 위조·범위 상한·중복·파일/네트워크/프로세스 접근 거부 및 결정성을 검증한다. 정확한 GitHub CI SHA 테스트와 로컬 실호스트는 별개다.

## 미래 작업을 기존 P10에서 처리할 경우의 분리 원칙
1. **정해진 UCIE 내부 작업자**만 명시적으로 승인·고정. 모델/외부 API 호출을 기본 동작으로 만들지 않고 별도 사용 권한과 예산/품질 테스트를 요구한다.
2. 수집 → 구조화·중복/버전 비교 → 라이브러리 후보 분류 → 원리·문장·스킬서적의 실제 재가공 → 독립 안전 시험 → 권리·사람 검토 → 승인된 재사용 출력의 단계별 계약을 따로 검증한다.
3. 비용 계측: **스킬 후보당 작업 시간, CPU·메모리, 재검증 시간, 동등 결과 캐시 히트, 새 기술 채택률, 과거 자산 유지비**, 외부 모델 요청 수. 현재 코드 경로의 0호출을 전체 지식 생성 비용 0으로 일반화하지 않는다.
4. 생성형 추론이 필요한 작업은 우선 **규칙·템플릿·제한된 독립 테스트**로 품질을 측정하고, 충족하지 못할 때만 별도 승인된 로컬 모델 또는 외부 모델을 비교 평가. 비용뿐 아니라 오류율·재현·라이선스·권리·성능을 동시에 비교.
5. 고객 의뢰 데이터는 공용 UCIE 원장이 아닌 별도 권한/계약 경계를 요구한다. **현행 프로젝트에 어떤 고객 코드 통합 경로도 만들지 않는다.**

## 정직한 현 상태
- 메타데이터 배치 로직: **코드 작성, 테스트 결과 확인 전**.
- 일반적인 스킬서적 본문 자동 집필·의미적 재가공: **미구현**.
- 외부 유료 AI API가 필수인 내부 업무: **현재 구현된 배치에서는 없음**.
- P10 새 작업 연결/스케줄 변경/운영 활성화: **없음**.
- 실제 서버 원가·처리량·동시접속 성능: **미측정**.
- 재사용 패키지 독립 검증·상용 공개: **NO_GO**.
