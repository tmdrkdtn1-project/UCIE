# UCIE 첫 사용 경험 개선 — 소유자 로컬 우선 (2026-11-15)

## 이번에 해결할 사용자 질문

"그래서 이걸 가지고 뭘 어떻게 해? 뭐가 좋고, 뭐가 사용 가능해? 어떻게 쓰지? 언어가 너무 복잡해."

기능 개발은 충분히 진행됐지만 실제 소유자/고객의 태스크 중심 안내가 부족하다는 피드백을 **UX 결손**으로 접수했다. 자동 수정·승인·상용 배포 기능이 완성됐다는 뜻으로 처리하지 않는다.

## 실제 변경: 기존 UCIE Local V04에만 적용

- 홈 상단 바로 아래 **세 가지 선택**: ① 공개 오류 사례 찾아보기, ② UCIE 자체 예제 실행하기, ③ 기술 사용 가이드 찾기. 전부 존재하는 기존 로컬 GET 링크로 이동하며 별도 계정·설정·외부 코드가 필요 없다.
- 홈에서 사용 가능(공개 검색·UCIE 예제·가이드), 추가 확인 필요(공개 후보 수정 효과·버전), 제공하지 않는 것(사용자 코드 자동 검사·수정)을 한눈에 구분한다.
- 네 기능 전체 메뉴, Python/PowerShell/Git/MCP 추가 예제는 강제 튜토리얼이 아닌 기본 닫힌 `<details>`를 통해 원하는 경우에만 펼친다. 선택하지 않아도 첫 화면에서 시작할 수 있다.
- 오래된 PR/pattern 코드명은 공개 기술 **검색 카드 제목에서는 쉬운 한국어로 표기**하고, 원문 코드·SHA·출처·검증 상태는 기존 상세 정보에 보존한다. 미등록 패턴에는 승인을 암시하는 번역을 만들지 않는다.
- 선택한 공개 후보 검토 화면에서는 먼저 '무엇을 알 수 있는지'와 원본으로 가는 링크를 보여주고, 영문 기술 가이드·시험 설계·실제 적용 전 긴 점검 목록은 선택적으로 펼친다. 버튼도 '안전한 예제 실행해 보기'로 단순화한다.
- 기존 V04 그래파이트 다크 테마를 유지하고 추가 카드만 한정된 반응형 CSS로 꾸몄다. 링크 이름, 키보드 포커스, 모바일 1열, 입력 없이 건너뛰기, 감소 동작 선호와 CSP는 유지한다.
- 스킬북 두 권, 4대 엔진, 진짜 W04 공개 근거 원장, 권리/검증 게이트, 저장소 코드, GitHub CI는 기존 동작 유지. **사용자 임의 파일 분석·자동 수정·실제 PR 수정 효과 독립 검증은 이번 작업에 포함하지 않는다.**

## 쉬운 사용 예시 (소유자 Windows)

기존 명령 하나:

```powershell
& 'D:\UCIE\scripts\start_ucie_local_v1.ps1'
```

로컬 브라우저 홈에서 아래 중 하나만 선택한다.

- 오류가 걱정되면 **공개 오류 사례 찾아보기**. Python 관련 기존 사례와 확인할 점을 먼저 읽는다.
- 어떤 성능 차이가 있는지 궁금하면 **예제 직접 체험하기**. 합성 숫자를 바꿔 UCIE 알고리즘 비교를 확인한다. 실제 프로그램 CPU 성능 보장은 아니다.
- Git을 공부하고 싶으면 **기술 사용 가이드 찾아보기**. Git SkillBook/공개 근거를 살펴보고 직접 예제 체험으로 이동한다.

이전 저장소 기술 원문, 무관한 프로젝트, 고객 파일·소스·비밀, 운영 DB, C40, 스케줄러, 결제, 상용 키, 배포 대상은 접근하거나 변경하지 않는다.

## 검증과 남는 단계

소유자 Windows 대상 파일 정확 SHA 임대/백업 + 신규 파일 ABSENT-only. 새 첫 사용 UI/한국어/의미·검증 경계/안전한 직접 링크/HTML 구조/모바일 CSS/localhost GET·POST 방어 시험과 기존 V04, 실제 W04 원장 시험 및 전체 CI를 구분하여 보고한다.

**아직 미완료:** 사람이 실제 Windows 브라우저에서 스크린샷/모바일/키보드 탭 순서 등을 보고 승인하는 UX 인수, 사용자 자유 입력 코드 분석·수정. CI 성공만으로 실제 사용자 만족도 'PASS'를 표시하지 않는다. 정기결제·고객 배포는 계속 보류한다.

UX Pro Max 내부 오프라인 검색 근거: ux-guidelines.csv (onboarding: 사용자는 튜토리얼을 건너뛸 수 있어야 함; accessibility: 입력 라벨/동작 이름 필요; responsive: 모바일부터 구성). 기존 V04의 실제 승인 시각 계약이 우선이며 새 테마 교체는 하지 않음.
