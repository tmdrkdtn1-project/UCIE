## Locked four coequal product missions

1. Coding error prevention with grounded risk, safe calls, exact version limits and regression evidence.
2. Practical development/maintenance engines, skills, algorithms and learning-logic discovery and improvement; positive techniques are as important as bug fixes.
3. **Virtual Library as active reasoning and knowledge production**, not a passive search or PR list: approved public technical evidence and UCIE-authorized tests -> mechanism/principle extraction -> cross-source comparison -> bounded generalization hypotheses -> negative controls and UCIE authored trials -> reclassification -> human SkillBooks plus machine-consumable original engine/skill/test/learning contracts -> lineage, review, approval.
4. UCIE-native continual improvement: source-linked revisions, hypothesis failure learning, re-evaluation and retraction. No other-project or customer private learning.

The Virtual Library is the shared central product foundation, and continual improvement is a repeating loop, never an optional last feature.
