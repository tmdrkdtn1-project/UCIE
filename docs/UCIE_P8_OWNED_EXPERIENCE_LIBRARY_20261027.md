# UCIE P8 — 경험 도서관과 개선 이력의 첫 실제 폐회로 (2026-10-27)

## 현재 기준과 사용자 실험 증거

사용자가 2026-10-27 Windows에서 수행한 **W08 실제 합성 실험**:
- `UCIE_LIBRARY_EXACT_KEY_INDEX_EXPERIMENT_V1`, 합성 1,536 항목, 48개 조회, 3회 측정, 원본 실험 자료 SHA256 `cd68799042a9c6c57b15100947541f16731d4cfd18efe6088db85264e92227f7`.
- 선형 전체 검색 73,728회 검사 / 복합 인덱스 생성+조회 1,584회, 정확도 48/48, 42 성공 및 6 없는 키, 연산 감소 72,144회.
- 기준선 중앙값 6,409,500ns, 인덱스 방식 중앙값 218,100ns (해당 합성 실험 약 29.39배).
- 이 영수증은 **소유자 제공 과거 관측**이며, 본 코드가 임의로 실제 호스트 실행을 대체하거나 그 원본 영수증을 새로 생성했다고 주장하지 않는다. 기존 해당 정본은 `docs/UCIE_W07_W09_VERIFIED_RULEPACK_LIBRARY_20261027.md`에도 기록돼 있다.

## P8 실제 구현 내용

신규 코드: `src/ucie_miner/experience_library.py`

- `inspect_experience_library(root)`: **기본 읽기 전용**. 파일/DB가 없으면 `UCIE_EXPERIENCE_LEDGER_EMPTY_NO_GO`로 반환하고 폴더도 만들지 않는다.
- `record_owned_experiment(root, allow_write=True)`: **소유자가 명시적으로 기록을 요청한 경우에만** W08의 원본 `evaluate_synthetic_library_index`를 실제로 다시 실행. 외부에서 받아온 PR/스킬/다른 프로젝트의 성능 자료나 임의 JSON을 운영 경험으로 수입하지 않는다.
- `D:\UCIE\runtime\ucie_experience_v1\r_<sha256>.json` 이름으로 **새 파일만 원자적 생성**(`os.link` no-overwrite). 원본 W08 응답 중 합성 데이터 해시, 알고리즘 ID, 워크로드, 정답 일치/불일치, 연산량, 시간 중앙값, 적용 한계의 **허용된 정형 메타데이터만** 기록. 사용자 경로/명령/외부 소스코드/자격증명/모델 파일 저장 금지.
- 같은 합성 데이터 해시·항목수·쿼리수인 실험의 다음 결과는 이전 `record_id`를 `parent_record_id`로 연결하고 `revision_number`를 증가시킨다. 서로 다른 워크로드의 속도 개선을 직접 비교하지 않는다.
- 재조회 시 정형 필드·날짜·허용 범위·계산 일치·SHA256 파일 해시·부모 계보 검증. 변조 또는 중간 기록 삭제는 **NO_GO**, 자동 복구/자동 신뢰 복원하지 않는다.
- 동일 실험의 실행 시간 변화와 연산량 변화 등 `comparisons`를 제공하며 **어떤 성능 관측도 자동 승인·운영 반영하지 않는다.** 실패 실험도 원인 검토를 위해 별도 경험으로 남긴다.
- 저장 최대 128건, 한 파일 최대 8KiB, 조회 20건 제한. 실제 운영 원장/기존 수집기/스케줄러/서명 키·패키지 손대지 않는다.
- SHA 해시는 **변조 흔적 검출용**이지 외부 공격자에 대한 인증·서명이 아니다. 파일 시스템 관리자라면 해시도 다시 계산할 수 있으며 이 기능을 독립 QA/보안 인증으로 표시하지 않는다.

## 소유자 PC에서의 사용

PR 병합 후 정확한 `experience_library.py` 한 파일이 UCIE 로컬에 반영되어 있어야 한다.

```powershell
$env:PYTHONPATH = 'D:\UCIE\src'
$py = 'D:\UCIE\.venv\Scripts\python.exe'

# 기본 읽기 전용: 저장 없이 경험 현황만 조회
& $py -B -m ucie_miner.experience_library

# 명시적으로 지정할 때만 새로운 W08 실험 실행 + 경험 기록 1건 생성
& $py -B -m ucie_miner.experience_library --record --rows 1536 --queries 48 --repeats 3

# 다시 기록하면 동일 워크로드의 이전 경험과 부모/개정 이력 연결
& $py -B -m ucie_miner.experience_library --record --rows 1536 --queries 48 --repeats 3

# 저장된 이전 경험과 재실험의 차이를 읽기 전용으로 비교
& $py -B -m ucie_miner.experience_library --limit 10
```

**기존 사용자가 제공한 W08 수치가 이 새 원장에 자동 등록되는 것이 아니다.** 데이터 생성/영속 기록은 `--record`를 실행한 시점의 새로운 합성 실험만 대상으로 한다.

## 검증 / 수용 경계

`tests/test_ucie_p8_experience_library.py`는 임시 `UCIE` 디렉터리에서 자체 W08 실제 실행 → 명시적 저장 → 재조회 → 같은 워크로드 부모 링크/시간 변화 → 다른 워크로드 분리, 변조된 해시와 상위 기록 누락 거부, 외부 경로/가짜 승인 거부, 실패 실험의 불승인 기록, 기본 명령 GET·쓰기 0 검증.

단, CI는 오프라인 합성 환경에서 소스의 정합성만 입증한다. 소유자의 **로컬 Windows 명시적 --record 실행**과 운영 경험 품질은 별도 관측이다.

## 다음 실질 작업

P8 경험 도서관이 실질적으로 채워진 뒤, **사용자가 승인한 UCIE 자체 실험 실패/개선 가설을 이용해 후속 실험 구성을 선택**하고, 동일 조건에서 개선 전/후를 평가하는 순환을 연결한다. 그다음 **W09 범용 엔진·스킬·학습 로직의 개별 독립 소비 계약 및 P9 통합 E2E**로 진입한다. 승인되지 않은 출처 확대, 다른 프로젝트 정보 수집, 자동 서명/규칙 승격, 무인 모델 가중치 갱신은 수행하지 않는다.
